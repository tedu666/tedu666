#### 游玩卡顿问题解决

若出现以下几种情况的卡顿，说明您可能需要调整某些高级设置以降低游玩体验：

1. 在关卡开始后严重卡顿并掉帧 => 方案①

2. 您是IOS设备且在原版JSPVZ上运行良好 => 方案②

上述问题中对应的方案：

​	①：进入高级设置页面，将“子弹设置”中的“画布设置”改为“单层画布”

​	②：进入高级设置页面，将“音频设置”中的“音频播放总开关”改为“强制静音”

说明：

* 高级设置页面入口位于游戏初始界面，点击左上角标靶图案即可进入

* 您需知晓，调整这些设置后可能会降低预期游玩体验
